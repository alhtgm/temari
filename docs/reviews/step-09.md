# step09: 楽しく続ける機能（今週のようす・たび・たいそう）

## 1. やったこと
- ホームに「今週のようす」（つづけて記録 ◯日・たいそう ◯回・月〜日の ★●○）を追加し、メニューを 2×2 のタイル（ふりかえり・ビンゴ・たび・たいそう）にした。
- 「たび」画面: これまでの歩数を距離に直し、東海道（日本橋 → 京都 三条大橋）の上の位置・つぎの宿場まで・宿場の一覧を出す。
- 「たいそう」画面: 座ってできる体操 5 種類を選び、「よーい」3 秒 → 30 秒の数え下げ → 「よくできました！」と紙ふぶき。終えると今日の回数が増える。

## 3. 実機で確認する手順と、期待される見た目・動き
1. ホームを下までスクロール → 「📅 今週の ようす」に「🔥 つづけて記録 ◯日」「🤸 たいそう ◯回」、月〜日の印（今日は枠つき、まだ来ていない日は「・」）。
2. 「🗾 たび」→ 緑から藍のカードに「◯◯ km」「これまで ◯◯歩」、点線の道の上に手まりちゃん、「京都まで ◯%」。その下に「つぎは ◯◯」「あと ◯ km（約 ◯歩）」と、✓／○ の付いた宿場の一覧と「👟 いま ここ」。
3. スタッフ用で「よく動いた日」にすると、たびの距離が伸び、つづけて記録の日数が増える。
4. 「🤸 たいそう」→ 体操の一覧。「▶️ はじめる（30秒）」→「よーい…」3,2,1 → 「いっしょに やりましょう！」と輪が減っていく数え下げ。画面は消えない。
5. 30 秒たつと手まりちゃんが大よろこびで「よくできました！」と紙ふぶき。「きょうの たいそう」が1回増える。「ほかの たいそうへ」で一覧、「もどる」でホーム。ホームの「たいそう ◯回」も増えている。
6. 体操の途中で「おわる」または Android の戻る操作 → 一覧に戻る（回数は増えない）。
7. 特大の文字で、たび・たいそう・ホームの今週のようす が切れたり重なったりしない。

## 4. 判断を保留した点
- **体操の内容と秒数**: 5 種類・各 30 秒は仮。リハビリ型デイサービスなので、施設の理学療法士などに内容を確認してもらいたい。
- **体操はポイントに足していない**: 「たいそう ◯回」として別に数えている。活動ポイントに足すかどうかは、本物の計測で体操の動きがどれくらい数えられるかを見てから決めたい。
- **東海道の距離**: 宿場までの距離はおおよその値（仮）。歩幅 0.55m も仮。京都に着いたら2周目に入る。
- **つづけて記録の数え方**: 今日の記録がまだ無いときは昨日から数える（朝いちばんに「0日」と出さないため）。
- **モックの「これまでの歩数」**: 今週の歩数＋シナリオごとの決めた値。モックで体操の回数を増やしても、シナリオを切り替えると元に戻る。
- **ホームが長い**: 今週のようす はメニューの下に置いた（メニューを先に見せるため）。
