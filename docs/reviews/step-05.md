# step05: ビンゴ

## 1. やったこと
- SPEC_UI.md 3.3 のビンゴ（今週の期間の見出し、3×3 のマス、開いたマスの色と ✓、マスを押すと説明のダイアログ）を作った。
- 1列そろうと大きな「ビンゴ！」が弾むように出て、そろった列にオレンジの線が端から伸びていく演出を付けた。
- マスの名前と説明はすべて strings.xml に置き、説明の中の数字（しきい値・時刻）は config の定数から入れるようにした。

## 2. 追加・変更したファイルと役割
| ファイル | 役割 |
|---|---|
| `ui/bingo/BingoViewModel.kt` | ビンゴカードと、説明を開いているマスを持つ |
| `ui/bingo/BingoScreen.kt` | `BingoRoute` と `BingoScreen`（マス・線・お祝い・ダイアログ）。プレビューは よく動いた日／ダイアログ × 大／特大 |
| `ui/bingo/BingoTexts.kt` | マスの種類 → 名前・説明の文字列 |
| `config/UiConfig.kt` | マスの最低の高さ、線の太さと不透明度、アニメーションの時間と始まりの大きさ |

| `res/values/strings.xml` | ビンゴの見出し、マスの名前と説明、ダイアログの文言 |

## 3. 実機で確認する手順と、期待される見た目・動き
1. ホーム →「ビンゴ」。上に「今週のビンゴ（10月12日〜10月18日）」（その週の月曜〜日曜）。
2. 3×3 のマス。開いたマスは緑の塗りつぶしに白い「✓」と名前、まだのマスは白地に黒い名前。真ん中の「フリー」は最初から開いている。
3. マスを押す → 大きな文字のダイアログ（名前・開いていれば「✓ あきました」・条件の説明）。「とじる」で閉じる。
4. ふつうの日（初期値）では列はそろわない（木曜の場合）。
5. `AppContainer.kt` の `INITIAL_SCENARIO` を `Active` にすると、画面を開いたときに「ビンゴ！」が弾むように大きくなり、そろった列にオレンジの線が伸びる（step06 以降はスタッフ・開発用画面から切り替えられる）。

## 4. 判断を保留した点
- **開いたマスの色**: 緑の塗りつぶし＋白い文字＋「✓」。色だけに頼らないよう「✓」を必ず付けた。
- **マスの並び**: 仕様の表の順ではなく、ふつうの日で列がそろわないよう並べた（上段: 朝からげんき／目標たっせい／家のことマスター、中段: 夜もすこし／フリー／よく歩いた日、下段: 3日つづけて記録／目標たっせい×3／毎日コツコツ）。
- **演出の出るとき**: 画面を開いたとき、またはそろった列の数が変わったときに1回だけ。何度も動き続けると気が散るので、くり返しはしない。
- **複数の列がそろったとき**: すべての列に線を引く。「ビンゴ！」は1つだけ出す。
- **まだ開いていないマスの読み上げ**: 「◯◯、これから」とした（否定的な言葉を避けるため）。
- **ダイアログの外側を押したとき**: 「とじる」と同じく閉じる（利用者が迷わないように）。
- **特大のとき**: マスの名前が2〜3行に折り返し、マスの高さが伸びる。同じ行のマスは高さをそろえている。
