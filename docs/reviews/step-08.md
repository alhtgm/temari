# step08: デザインの一新

## 1. やったこと
- 色を手まりの和の配色（藍・朱・若竹・山吹）に替え、角の大きなカード・うすい影・背景のグラデーションで今風の見た目にした。
- キャラクター「手まりちゃん」を Canvas で描き、ホームの進み具合の輪の中と、ひとことメッセージの吹き出しに置いた。進み具合で表情が変わり、ゆっくり弾む。
- 数字のカウントアップ、輪が伸びる動き、目標たっせい・ビンゴの紙ふぶき、グラフの棒が伸びる動き、点滅する「記録中」を付けた。

## 3. 実機で確認する手順と、期待される見た目・動き
1. ホームを開く → 上に日付と「◯◯さん、こんにちは」。藍色のカードの数字が 0 から増え、黄色〜朱色の輪が伸びる。輪の中で手まりちゃんが弾む。
2. カードの下に「目標まで あと ◯◯」と「目標 600 ポイント（70%）」。
3. 朱色の吹き出しの中に手まりちゃんと、ひとことメッセージ。その下に「👟 歩いた」「🏠 家のこと」のタイル。
4. 緑の点がゆっくり点滅して「記録中」。下に「📊 ふりかえり」「🎯 ビンゴ」の大きなタイル、一番下に「⚙️ せってい」。
5. スタッフ用でシナリオを「よく動いた日」にする → ホームに戻ると「🎉 目標たっせい！」、手まりちゃんが大よろこびの顔、紙ふぶきが降る。
6. ふりかえり → 棒が下から伸びる。きょう／今週 を切り替えるたびに伸び直す。
7. ビンゴ（よく動いた日）→ マスに絵文字、開いたマスは緑で「✓」。1列そろうと「ビンゴ！」と線、画面全体に紙ふぶき。
8. せってい を「特大」にして各画面を見る → 文字が切れたり重なったりしない（ホームはスクロールで下まで見られる）。

## 4. 判断を保留した点
- **ホームが長くなった**: カード・吹き出し・タイルが増えたので、メニューのタイルはスクロールしないと見えない端末がある。よく使うメニューを上に出すかは、利用者に見てもらってから決めたい。
- **絵文字の見た目は端末で違う**: 絵文字は Android の標準の絵文字で出すので、メーカーによって絵柄が少し違う。意味は必ず文字でも出している。
- **輪の中は手まりちゃん**: 数字を輪の中に入れると、特大の文字で輪からはみ出すため、数字は輪の上に出した。
- **紙ふぶきの間隔**: 目標たっせいの紙ふぶきは、ホームを開くたびに1回降る。うるさく感じるようなら「その日の1回目だけ」にする。
- **@Preview の確認**: Android Studio が無い環境なので、プレビューの絵はまだ見ていない（ビルドは通っている）。
