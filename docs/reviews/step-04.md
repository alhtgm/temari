# step04: ふりかえり

## 1. やったこと
- SPEC_UI.md 3.2 のふりかえり（「きょう」「今週」の切り替え、積み上げ棒グラフ、凡例、「いちばん動いたのは ◯◯ でした」）を作った。
- グラフは外部ライブラリを使わず Canvas で自作した。家のこと側は斜線の模様にし、今週の目標達成日には「★ たっせい」を付けた。
- 「いちばん動いた」の選び方と、今週7日分の並べ方の単体テスト 3 件を追加した。

## 3. 実機で確認する手順と、期待される見た目・動き
1. ホーム →「ふりかえり」。上に「✓ きょう」（青の塗りつぶし）と「今週」（白地に枠）の2つの大きなボタン。
2. きょう: 朝・昼・午後・夜 の4本の棒。下が青（歩いた）、上がうすい緑に濃い緑の斜線（家のこと）。ふつうの日・15時なら、朝と午後が高く、夜は 0。
3. グラフの下に凡例「■ 歩いた」「▨ 家のこと（しゃせん）」と、「いちばん動いたのは 朝 でした」（または 午後）。
4. 「今週」を押す → 「✓ 今週」に切り替わり、月〜日の7本。記録の無い日とまだ来ていない日は棒なし。目標を達成した日には棒の上にオレンジの「★」と「たっせい」。文章は「いちばん動いたのは ◯曜日 でした」。
5. 「もどる」でホームへ。もう一度開くと「きょう」から始まる。
6. 特大での見た目は、step06 で文字サイズを切り替えられるようになってから確かめる（プレビューでは確認できる）。

## 4. 判断を保留した点
- **棒の高さの基準**: いちばん高い棒をグラフの高さいっぱいにしている（目標の線は引いていない。仕様に無いため）。
- **「たっせい」の文字**: 今週は棒が7本あり1本分の幅がせまいので、特大では「たっ／せい」のように折り返す。折り返しても棒の根元はそろうようにした。実機で読みにくければ、★だけにして凡例で説明する案もある。
- **データが無いときの文章**: どこも 0 のときは「これから すこしずつ 動いていきましょう」とした（否定的な言葉を避けるため。仕様に文言の指定なし）。
- **凡例の文字**: 模様が伝わるよう「家のこと（しゃせん）」とした。
- **棒の上の数字**: 仕様に無いので出していない。読み上げ機能（TalkBack）では各棒のポイントを読み上げる。
- **選んだモードは覚えない**: 画面を開くたびに「きょう」から始まる。
