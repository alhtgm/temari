# step03: ホーム

## 1. やったこと
- SPEC_UI.md 3.1 のホーム（あいさつ、きょうの活動ポイントと進み具合バー、内訳2行、ひとことメッセージ、記録の状態、ボタン）を作った。
- 5章のひとことメッセージの選び方を `HomeMessage.select` にまとめ、単体テスト 7 件を追加した。
- ViewModel と、アプリ全体の部品をまとめる `AppContainer` を作り、画面がモックのリポジトリからデータを受け取るようにした。

## 2. 追加・変更したファイルと役割
| ファイル | 役割 |
|---|---|
| `TemariApplication.kt` / `AppContainer.kt` | アプリ全体で1つのリポジトリなどを持つ入れ物。起動時のシナリオ `INITIAL_SCENARIO` もここ |
| `AndroidManifest.xml` | `TemariApplication` を使うよう指定 |
| `config/HomeConfig.kt` | あいさつの時間の区切り（4時／10時／18時） |
| `config/UiConfig.kt` | 小さい余白・角の丸み・枠線・進み具合バーの高さなどを追加 |
| `ui/home/HomeMessages.kt` | あいさつ（`Greeting`）とひとことメッセージ（`HomeMessage`）の選び方 |
| `ui/home/HomeViewModel.kt` | ホームの状態（`HomeUiState`）を作る。「再開する」を受け取る |
| `ui/home/HomeScreen.kt` | `HomeRoute`（ViewModel とつなぐ）と `HomeScreen`（表示だけ）。プレビューは ふつうの日／記録が止まった × 大／特大 |
| `ui/common/Ticker.kt` | 1分ごとに「今」を流す（開いたままでも あいさつ が時刻に追いつく） |
| `ui/common/Labels.kt` | 時間帯の名前（朝・昼・午後・夜）の文字列 |
| `ui/common/PreviewData.kt` | プレビュー用のモックデータ（木曜15時に固定） |
| `ui/theme/Color.kt` | 「記録が止まっています」用の濃いオレンジ枠とうすいオレンジ背景 |
| `ui/navigation/AppNavHost.kt` | ホームを `HomeRoute` に差し替え |
| `res/values/strings.xml` | ホームとメッセージの文言、時間帯の名前 |
| `test/.../HomeMessageTest.kt` | メッセージとあいさつのテスト |
| `gradle/libs.versions.toml`、`app/build.gradle.kts` | lifecycle-viewmodel-compose / lifecycle-runtime-compose を追加（開発者の了承済み） |

## 3. 実機で確認する手順と、期待される見た目・動き
1. アプリを開く → 上に「こんにちは」（時刻で おはようございます／こんばんは）。呼び名の保存は step06 で作るので、今は名前なし。
2. 灰色のカードに「きょうの活動ポイント」、大きな青い数字（ふつうの日 なら目標 600 の 70% で 420）、進み具合バー、「目標まで あと 180」、「目標 600」。
3. その下に「歩いた ◯◯ポイント（約 ◯◯歩）」「家のこと ◯◯ポイント」。
4. 緑の文字のひとこと（ふつうの日・15時なら「朝によく動けましたね」など）と、小さく「● 記録中」。
5. シナリオの確認: `AppContainer.kt` の `INITIAL_SCENARIO` を書き換えてビルドし直す。
   - `Active` → 数字が目標を超え、「目標たっせい！」「目標たっせい！ すばらしいです」。
   - `Low` → 約 120。「目標まで あと 480」。
   - `Stopped` → オレンジの太い枠で「記録が止まっています」と「再開する」。メッセージは「記録を再開しましょう」。「再開する」を押すと枠が消え「● 記録中」に変わる。
   - `FirstDay` → 数字がとても小さい（約 30）。
6. 文字を特大にしたときの見た目は step06 で文字サイズを切り替えられるようになってから確かめる（今は Android Studio のプレビューで 大／特大 を見られる）。

## 4. 判断を保留した点
- **呼び名**: 保存は step06 なので、今は空（「こんにちは」だけ）。空のときは名前を付けない。
- **あいさつの時刻**: おはようございます 4〜10時、こんにちは 10〜18時、こんばんは 18〜翌4時とした（仕様に時刻の指定がなかったため）。
- **「今の時間帯まで」**: 今の時刻より前に始まった時間帯（今の時間帯を含む）の中で、いちばん活動ポイントの多い時間帯を選ぶ。
- **目標を超えたときのバー**: いっぱいで止める（はみ出さない）。超えたことは「目標たっせい！」の文字で伝える。
- **止まったときの色**: 赤は「失敗」の印象が強いので、濃いオレンジの太い枠にした。
- **数字の区切り**: 1,000 以上は「1,234」のようにカンマを付ける。
- **ホームの中身が長い**: 特大＋端末の文字サイズ大では1画面に収まらず、スクロールが必要になることがある。実機で確かめたうえで、カードの並びを詰めるかどうかを決めたい。
