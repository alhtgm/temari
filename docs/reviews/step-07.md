# step07: 初回設定

## 1. やったこと
- SPEC_UI.md 3.6 の初回設定6画面（ようこそ → よび名 → お知らせの許可 → 電池の設定 → 1日の目標 → じゅんびができました）の中身を作った。
- よび名を入れて進むと利用者ID（UUID）を発行して保存し、最後の「はじめましょう」で「初回設定済み」を保存する。起動時はそれを見て、初回設定かホームかを決める。
- スタッフ・開発用の「初回設定のやり直し」に確認ダイアログを付け、設定を消して初回設定の最初に戻れるようにした。あわせて、ボタンの二度押しで画面が2つ進んだり戻りすぎたりしないようにした。

## 3. 実機で確認する手順と、期待される見た目・動き
1. 前の版が入っている場合は、一度アプリを削除してから入れる（保存済みの設定を消すため）。
2. 開く → 「ようこそ」（説明3行と「つぎへ」だけ。「もどる」は無い）。
3. 「つぎへ」→「よび名」。名前を入れて「つぎへ」。
4. 「お知らせの許可」→「つぎへ」を押すと Android の許可のダイアログが出る。「許可」でも「許可しない」でも次の画面へ進む。
5. 「電池の設定」→「電池の設定を ひらく」で Android の確認が出る。「許可」して戻ると「✓ 電池の設定は できています」になり、下のボタンが「つぎへ」に変わる。設定せずに「あとで」でも進める。
6. 「1日の目標」→「おすすめは 600 ポイントです」と「− へらす」「＋ ふやす」。
7. 「じゅんびができました」→「はじめましょう」でホームへ。入れた名前で「◯◯さん、こんにちは」。Android の戻る操作ではアプリが閉じる（初回設定には戻らない）。
8. アプリを終了して開き直す → 初回設定は出ず、ホームが直接出る。
9. せってい →「スタッフ用」を2秒長押し → 利用者ID（UUID）が表示されている。「初回設定のやり直し」→ 確認ダイアログ →「やり直す」で「ようこそ」へ。「やめる」なら何もしない。
10. ボタンを素早く2回押しても、画面は1つだけ進む（戻る）。

## 4. 判断を保留した点
- **やり直しで消すもの**: よび名・目標・文字の大きさ・利用者ID・初回設定済み をすべて消す（別の利用者に渡す場合を考えて、新しい ID を発行し直す）。同じ利用者のまま設定だけやり直したい場合は ID を残す方がよいので、運用に合わせて決めたい。
- **よび名が空でも進める**: スタッフと一緒に設定する前提なので止めなかった。空ならあいさつは「こんにちは」だけになる。
- **通知の画面のボタン**: 「つぎへ」を押すと許可のダイアログが出る形にした（ボタンを1つにするため）。すでに許可済みなら「✓ お知らせは 許可されています」と出て、そのまま進む。
- **電池の設定（Google Play の方針）**: `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` は Google Play で配布するときに使い道の説明が必要になる権限。施設内での配布なら問題ないが、ストアで配布する場合は見直しが必要。
- **設定を読み込むまで**: 起動直後のほんの一瞬、背景だけの画面が出る。
- **目標の画面の値**: 「−」「＋」を押すたびにすぐ保存する。
- **二度押し対策**: 画面の切り替えの途中に届いた操作は無視する。許可のダイアログから戻ったときは、画面が操作できる状態に戻ってから次へ進む。
