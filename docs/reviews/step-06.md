# step06: せってい と スタッフ・開発用

## 1. やったこと
- せってい（3.4）に、文字の大きさ（大／特大）、呼び名の変更、1日の目標（「−」「＋」）を作り、DataStore に保存するようにした。
- 保存した文字の大きさをアプリ全体のテーマに反映し、目標はモックの「今日の目標」に、呼び名はホームのあいさつにつないだ。
- スタッフ・開発用（3.5）に、シナリオの切り替え（全画面にすぐ反映）、利用者ID、初回設定のやり直し、「準備中」の項目を作った。

## 3. 実機で確認する手順と、期待される見た目・動き
1. ホーム →「せってい」。上から「文字の大きさ」（✓ 大／特大）、「よび名」（入力欄と「よび名を ほぞんする」）、「1日の目標」（600 ポイント、「− へらす」「＋ ふやす」）。
2. 「特大」を押す → その場で全体の文字が大きくなる。ホーム・ふりかえり・ビンゴも特大になり、文字が切れたり重なったりしない。
3. よび名に「はなこ」と入れて「よび名を ほぞんする」→「✓ ほぞんしました」。ホームに戻ると「はなこさん、こんにちは」。
4. 「＋ ふやす」を2回 → 700 ポイント。ホームの「目標まで あと ◯◯」と「目標 700」が変わり、活動ポイントも目標の 70% に合わせて変わる（モックは目標の割合で値を作るため）。
5. アプリを終了（最近使ったアプリから消す）して開き直す → 特大・はなこ・700 がそのまま残っている。
6. せってい の一番下の「スタッフ用」を2秒押し続ける → スタッフ・開発用。シナリオを「よく動いた日」にして「もどる」2回でホームへ → 目標たっせい の表示に変わっている。ビンゴでは「ビンゴ！」が出る。
7. 「記録が止まった」を選ぶとホームにオレンジの枠と「再開する」。押すと「● 記録中」に戻る。
8. 利用者IDは、まだ初回設定を作っていないので「まだ発行されていません」（step07 で発行）。

## 4. 判断を保留した点
- **呼び名の保存のしかた**: 1文字ごとではなく「よび名を ほぞんする」を押したときに保存する（入力の途中の名前がホームに出ないように）。キーボードの「完了」でも保存する。
- **呼び名の長さ**: 最大10文字とした（仮）。
- **目標の幅と範囲**: 1回 50 ポイント、100〜2,000 の範囲（仮）。範囲の端でボタンを押しても何も変わらない（ボタンを灰色にすると見えにくくなるため）。
- **シナリオは保存しない**: アプリを開き直すと「ふつうの日」に戻る（開発用なので）。
- **スタッフ画面の文字**: 20sp 未満にしてもよい画面だが、テーマの文字スタイルがすべて 20sp 以上なので、そのまま使った。
- **`UserSettings.userId`**: 利用者IDを表示するため、項目だけ先に作った。発行は step07。
- **目標を変えたときのモックの値**: モックは目標に対する割合で値を作るので、目標を変えるとポイントも一緒に変わる。本物の計測では変わらない。
